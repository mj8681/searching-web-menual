# searching-web-menual
# 🔍 All-in-One Web Search Engine

순수 HTML, CSS, JavaScript만으로 구현한 **올인원 통합 웹 검색 포털**입니다. 별도의 백엔드 서버나 유료 API 키 없이도 브라우저 환경에서 백과사전, 이미지, GitHub 오픈소스 저장소를 실시간으로 검색하고 결과를 확인할 수 있습니다.

## ✨ 주요 기능

- **통합 카테고리 탭 검색**
  - **백과/지식 (Wikipedia):** 한국어 위키백과 실시간 문서 검색 및 요약 내용 미리보기
  - **이미지 (Wikimedia Commons):** 검색어와 관련된 이미지를 깔끔한 그리드(격자) 갤러리 형태로 제공
  - **개발/코드 (GitHub):** 오픈소스 저장소 이름, 별(★) 개수, 설명 실시간 조회
- **반응형 검색 레이아웃**
  - 초기 화면에서는 검색창을 중앙에 배치하고, 검색 실행 시 상단 헤더로 자연스럽게 이동하는 직관적인 UI 적용
- **샌드박스 오프라인 폴백(Fallback) 지원**
  - 온라인 코드 에디터나 오프라인 환경처럼 외부 통신이 차단된 환경에서도 멈추지 않고 내장 샘플 데이터를 통해 검색 동작 테스트 가능

## 🛠️ 사용 기술

- **HTML5:** 시맨틱 마크업 및 검색 폼 구조 설계
- **CSS3:** Flexbox 및 CSS Grid를 활용한 반응형 카드·이미지 갤러리 스타일링
- **JavaScript (ES6+):** `fetch` API 비동기 데이터 통신, `async/await` 예외 처리 및 동적 DOM 렌더링

## 🚀 실행 및 배포 방법

### 1. 로컬 환경에서 실행
1. 저장소의 `index.html` 파일을 다운로드합니다.
2. 크롬(Chrome), 엣지(Edge) 등 최신 웹 브라우저로 `index.html` 파일을 엽니다.

### 2. GitHub Pages로 웹 배포
1. GitHub 저장소의 **Settings** → **Pages** 메뉴로 이동합니다.
2. **Branch**를 `main`으로 설정하고 **Save**를 누릅니다.
3. 생성된 `https://<사용자아이디>.github.io/<저장소이름>/` 주소로 접속해 실시간 검색을 이용합니다.
